# 🛡️ VisionGuard AI — Intelligent Document & Identity Scanner Suite

## 🌟 Key Features

### 1. 📄 Scan & Document Quality Analysis
* **Readability & Clarity Scoring**: Analyzes resolution, sharpness, illumination, and contrast.
* **Auto Binarization & Enhancement**: Cleans scanned text documents using custom high-pass contrast filters.
* **Perspective & Skew Correction**: Bilinear transformation algorithms to de-skew documents photographed at an angle.

### 2. 😊 Facial Emotion & Age Analysis
* **Real-time Camera & File Upload**: Capture using device webcam/phone camera or upload images.
* **Emotion Breakdown**: Detects primary facial emotions (Joy, Surprise, Neutral/Calm, Sadness, etc.) with confidence scores.
* **Estimated Age Range**: Visual age classification with bracket ranges.

### 3. 🛡️ Privacy Mask & PII Redaction
* **Automated Sensitive Data Detection**: Detects phone numbers, emails, addresses, IDs, and financial numbers using multi-modal AI vision.
* **Client-Side Redaction Engine**: Performs localized blur or solid black masking over sensitive areas before sharing or exporting.

## 🛠️ Tech Stack & Architecture

| Layer | Technology | Purpose |
